✅ Step 1 — Install Node.js (if not installed)
Download from https://nodejs.org (LTS version), then verify:
bashnode -v
npm -v

✅ Step 2 — Install Angular CLI globally
bashnpm install -g @angular/cli
Verify install:
bashng version

✅ Step 3 — Create the Angular Project
Go inside your project folder first:
bashcd startuphub-frontend
Then create the Angular app:
bashng new startuphub --routing=true --style=scss
cd startuphub

✅ Step 4 — Install All Required Dependencies
bash# HTTP Client & Forms (built-in, just confirm in app.module)
npm install @angular/forms @angular/common @angular/router

# Angular Material (UI components)
ng add @angular/material

# JWT Token handling
npm install @auth0/angular-jwt

# Icons (optional but recommended)
npm install @fortawesome/fontawesome-free

# HTTP interceptor & guards support
npm install jwt-decode

# File upload support
npm install ng2-file-upload

# Charts/graphs for dashboard (optional)
npm install ng2-charts chart.js

✅ Step 5 — Generate All Modules
