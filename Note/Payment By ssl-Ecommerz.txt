## Setup Steps

### 1. Install Node backend dependencies

In your project root (same folder as `package.json`):

```bash
npm install express cors axios body-parser uuid
```

### 2. Place the files

```
LumiNex/
├── server.js                          ← NEW (root of project)
├── db.json
├── src/app/core/services/
│   └── payment.service.ts             ← REPLACE existing
└── src/app/client/payments/
    └── payments.ts                    ← REPLACE existing
```

### 3. Run all three servers

Open three terminals:

```bash
# Terminal 1 – json-server (existing)
npx json-server --watch db.json --port 3000

# Terminal 2 – SSLCommerz Node backend (NEW)
node server.js

# Terminal 3 – Angular
ng serve
```

### 4. Test the payment flow

1. Open `http://localhost:4200/client/payments`
2. Select a plan, choose **Online Payment**, click **Proceed to Pay**
3. SSLCommerz sandbox popup/page opens
4. Use test card: **4111 1111 1111 1111** (any future expiry, any CVV)
5. Or use bKash test: number **01711111111**, OTP **123456**
6. After payment, you'll be redirected back to the payments page with a success banner

## How the flow works

```
Angular (click Pay)
    │
    ▼
POST localhost:4000/api/payment/init
    │  (your Node server)
    ▼
POST sandbox.sslcommerz.com/gwprocess/v4/api.php
    │  (SSLCommerz returns a session + gateway URL)
    ▼
Angular opens SSLCommerz Easy Checkout popup
    │  (user pays with bKash / card / bank)
    ▼
SSLCommerz POSTs to localhost:4000/api/payment/success
    │  (Node validates + saves to db.json via json-server)
    ▼
Redirect → localhost:4200/client/payments?status=success
    │
    ▼
Angular shows success banner ✅
```

## Going Live

When you're ready to go live:
1. Register as a merchant at https://sslcommerz.com
2. In `server.js`, change:
   ```js
   const IS_LIVE = true;
   const STORE_ID = 'your_live_store_id';
   const STORE_PASSWORD = 'your_live_password';
   ```
3. Your backend must be publicly accessible (deploy to Railway, Render, VPS etc.)
4. Update `BACKEND_URL` and `FRONTEND_URL` in `server.js` to your production URLs
